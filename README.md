# Tourist
A "Bootstrapper" (installer) that simply helps you set up S.T.A.L.K.E.R Anomaly (and optionally) GAMMA, other mods may be supported later. Also, this is a personal thing I wanted because setting up anomaly + mods on linux through proton is miserable!

# INFO
This is NOT finished, nor is it polished, nor is it fully functional, there is no UI and it is entirely a CLI tool where you provide the files yourself

you should not use this, but you can if you really want

## Required system packages
7zip
unzip
libunrar
wine
curl
go (no precompiled binaries yet)
